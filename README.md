# Мои тренировки — Android

Android-оболочка актуального дневника из ветки `main`. Интерфейс и программа входят в APK и открываются без сети. После первого подключения результаты сохраняются на устройстве и синхронизируются с тем же зашифрованным файлом `training-data/diary.enc.json`, который используют сайт и ассистент.

- Пакет `ru.mytraining.diary` устанавливается отдельно от старой пробной версии `ru.mytraining.app`.
- Код подключения копируется на сайте через «Синхронизация → Код для другого устройства» и вставляется в приложение один раз.
- Excel сохраняется через системное окно Android.
- Для сигнала таймера при выключенном экране нужны разрешения на уведомления и точные таймеры.
- Подключение ассистента открывается во внешнем браузере; код предварительно копируется в буфер.
- Обновления интерфейса внутри APK выпускаются новой сборкой. История синхронизируется без переустановки.
- Приложение не содержит ключей GitHub, кодов восстановления или закрытого ключа подписи.

CI собирает неподписанный release APK. Окончательная подпись выполняется отдельно, закрытый ключ не входит в репозиторий или артефакты CI.

Проверки: сборка Android, инструментальные проверки автономной страницы, WebCrypto, подключения к Android и сохранения Excel через системный диалог на эмуляторе Android 15. Реальное подключение к GitHub и сигналы при выключенном экране дополнительно проверяются на телефоне пользователя.
