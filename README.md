# Мои тренировки

Статическое приложение для GitHub Pages. Публичный репозиторий не содержит историю, рабочие веса, имя пользователя или токены.

## Архитектура

- Интерфейс: этот публичный репозиторий, GitHub Pages.
- Данные: приватный репозиторий `my-training-data`, файл `data/training.json`.
- Авторизация: fine-grained PAT с `Contents: Read and write` только для репозитория данных.
- Токен существует только в памяти вкладки; после обновления страницы его нужно ввести снова.
- Незавершённая форма временно сохраняется в локальном хранилище браузера. В GitHub она попадает только после нажатия «Сохранить тренировку».

## Публикация

1. Загрузите содержимое этой папки в публичный репозиторий `my-training`.
2. В Settings → Pages выберите Deploy from a branch, ветку `main`, папку `/ (root)`.
3. Откройте выданный GitHub Pages URL.
4. Введите fine-grained PAT и имя репозитория `my-training-data`.

## Безопасность

Токен не записывается в `localStorage`, `sessionStorage`, URL или файлы. Он передаётся только GitHub API по HTTPS. Публичный репозиторий безопасно просматривать: персональных тренировочных показателей в нём нет.

Если GitHub вернёт конфликт версии, приложение не перезаписывает данные молча: повторите сохранение после повторного подключения.
