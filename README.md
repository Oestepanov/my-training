# Мои тренировки

Единственный актуальный дневник: https://oestepanov.github.io/my-training/github.html

- Интерфейс опубликован из ветки `main` этого репозитория.
- Все результаты хранятся в зашифрованном файле `training-data/diary.enc.json` (ветка `training-data`, файл `diary.enc.json`).
- Браузер и плагин ChatGPT читают и обновляют один и тот же файл с проверкой версии.
- Корневой `index.html` перенаправляет в актуальный дневник.
- Старая версия с PIN и отдельной историей отключена; её исходники убраны из текущей ветки.

Адрес https://ihoudini-training-diary.cuddlyhydrangea128.chatgpt.site теперь обслуживает только подключение ассистента и MCP-команды. Открытие корня перенаправляет в актуальный дневник. Старые `/api/*` возвращают 410 и не обращаются к истории.

На служебном сервере хранятся зашифрованные настройки доступа и выбор активной тренировки. Результаты упражнений сохраняются только в GitHub. Подключение доступно владельцу через «Синхронизация → Подключить ассистента». Исходники служебного сервера ведутся в отдельном репозитории Sites.

Инструкции по устройствам, шифрованию и конфликтам: [GITHUB_SYNC.md](GITHUB_SYNC.md).
Проверки клиентской синхронизации: `node --test github-store.test.cjs`.
