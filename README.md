# Мои тренировки

Личный дневник: три программы, результаты каждого подхода, история, графики, таймер отдыха и корзина.

- Интерфейс: GitHub Pages, этот репозиторий (main, корень).
- API и данные: Cloudflare Workers и D1. Текущий Worker опубликован через Sites: https://ihoudini-training-diary.cuddlyhydrangea128.chatgpt.site
- Просмотр доступен без аккаунта. Для записи новый браузер подтверждается четырёхзначным PIN. Можно запомнить его на 90 дней; отдельно отключить устройство можно на сайте.
- PIN и история не находятся в публичных файлах. В браузере хранится случайный ключ устройства; в D1 — только SHA-256 ключа.
- config.js содержит публичный адрес API. Никаких токенов GitHub посетителю вводить не нужно.

Серверный исходник — cloudflare/worker.js (самодостаточный модуль); API отдельно — cloudflare/api.js, SQL-миграции — cloudflare/migrations. Worker требует D1 binding DB и секреты PIN_HASH, PIN_SALT, INITIAL_TRAINING_DATA, INITIAL_TRAINING_DATA_2, INITIAL_TRAINING_DATA_3. Последние три значения — последовательные части одного JSON, каждый блок меньше 5 кБ. Хеш PIN: PBKDF2-SHA256, 100000 итераций, 32 байта в hex.

Cloudflare проверяет PIN и все операции записи. CORS разрешён для https://oestepanov.github.io и собственного origin API. Смена PIN отзывает все ключи устройств. Удаление переносит тренировку в корзину; восстановление защищено PIN. Сохранение старой записи проверяет её версию, чтобы не затирать правки с другого устройства.

GitHub Pages использует относительные пути к файлам. Публикация обновляется после коммита в main; root/manifest.webmanifest позволяет добавить сайт на главный экран телефона.

## Запись через ChatGPT

Плагин личного дневника предоставляет выбор тренировки, чтение предыдущих показателей и запись упражнений сразу из сообщения ассистенту. Три одинаковых подхода используются по установленному пользователем правилу, если количество не названо. Разные веса/повторы и отдельный подход поддерживаются. Повтор сообщения не создаёт дубликат занятия. Инструменты доступны только подтверждённому владельцу через Sites; email хранится в секрете ASSISTANT_OWNER_EMAIL. Публичный просмотр не даёт доступ к записи через MCP. При переносе Worker из Sites нужно заменить доверенные платформенные заголовки проверкой подписанной идентичности.

Открытый интерфейс обновляет внешние результаты каждые 15 секунд, пока пользователь не вводит свои изменения. Незавершённое занятие за сегодня можно продолжить на сайте.
